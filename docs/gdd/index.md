# Ashenreach — Game Design Document

> Single-player, browser-native open-world action RPG.
> Tagline: **Carry the dead home.**
> Engine: TypeScript + three.js (WebGL2), procedural assets, no third-party licences.

## One-line summary
A short, replayable action RPG about the weight of the dead: carry souls across a burning highland, bank them at cairns, and survive the rising Embertide.
