# 10 — Tech Spec

## Stack
- TypeScript + Vite + three.js (WebGL2).
- Vitest (unit), Playwright + SwiftShader (e2e boot/critic).
- Procedural assets generated by `tools/assetgen` (no external files at runtime).

## Architecture
- Fixed-timestep sim (60Hz) + interpolated render.
- Modules: core (RNG, Input, Audio, Save, Camera), world (Noise, Terrain, WorldGen, Meshes, Objects, WorldRenderer), entities (Rigs, Player), systems (Combat, Juice, Quests, Spawner, EnemyAI), ui (Widgets, Hud, Screens, MobileControls), data (Items, Enemies, Quests).

## Performance budget
- Desktop: 60fps, <= 400 draw calls, <= 120k tris on screen.
- Mobile: 30fps, <= 200 draw calls, scaled textures.
- Headless (QA): SwiftShader, draw-call bound; not a perf target.

## Build & verify
- `npm run build` -> dist/ (game + asset viewer).
- `npm run test` -> 28 unit tests.
- `node tests/e2e/run.mjs` -> boots headless, captures metrics + shots.
- `node tests/e2e/critic.mjs` -> hard-fail gates (luminance, colors, errors, enemies).

## Asset viewer
- `viewer.html`: orbit + inspector over every procedural model.
- Run `npm run dev` and open `/viewer.html`.

## Determinism
- All world/loot/asset gen seeded (Mulberry32). Same seed -> same world.
