# 06 — UI / UX

## HUD (in-run)
- Top-left: HP bar, stamina ring.
- Top-right: Embertide meter (0–10), run timer.
- Bottom-center: equipped weapon, combo counter.
- Bottom-left: mini objectives (active quests).
- Bottom-right: soul count (carried / banked).

## Menus
- Title: Play, Daily, Loadout, Codex, Settings.
- Pause (Esc): Resume, Loadout, Settings, Quit to title.
- Loadout: 4 weapon slots, charm, cloak, relic, skill glyphs.
- Death: score breakdown, best combo, souls banked, retry / title.
- Victory (Colossus felled): run summary, leaderboard position.

## Mobile
- Left virtual stick (move), right side: dash / attack / parry buttons.
- Auto-aim assist on touch (snaps swings to nearest enemy in arc).
- Scaled UI; HUD collapses to essential readouts under 420px.

## Accessibility
- Colorblind-safe palette (no red/green reliance for state).
- Remappable keys, scalable HUD (3 sizes).
- Subtitles for shade dialogue; audio cues doubled by on-screen pips.
- Reduced-motion option disables screen shake + ash drift.
