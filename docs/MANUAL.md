# Player Manual

## Goal
Carry the souls of the dead to the cairns. Bank them for score, or risk the Embertide for more. Survive.

## Desktop controls
| Action | Key |
| --- | --- |
| Move | W A S D |
| Sprint | Shift |
| Attack (light) | Left mouse |
| Attack (heavy) | Right mouse (hold) |
| Dash | Space |
| Parry | Right-click tap (within 200ms of hit) |
| Interact / pick up | E |
| Cairn map | M |
| Inventory / loadout | I |
| Pause | Esc |

## Mobile controls
- Left side: virtual move stick.
- Right side: dash, attack, parry buttons.
- Auto-aim assist snaps swings to the nearest enemy in arc.
- Tap interact prompts when near a soul / cairn.

## Core mechanics
- **Souls:** pick up to carry. Each slows you and feeds the Embertide.
- **Cairns:** safe points. Bank souls (score + reset Embertide), heal, save.
- **Embertide:** rises with souls carried and time. Bank to quiet it.
- **Weapons:** Blade / Maul / Spear / Censer — different reach, speed, stagger.
- **Combo:** consecutive hits escalate damage (up to x1.5).
- **Colossus:** wakes when you carry too much. End the run on your terms.

## Tips
- Bank early and often; hoarding is punished by the Embertide.
- Light new cairns — they reveal the map and grant a small score bonus.
- Parry beats blocking; time it.
- Daily seed = same map for everyone, once a day. Compare scores.
